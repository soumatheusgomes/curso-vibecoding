# Guia de prompts do curso

Prompts em português para criar e cuidar de sistemas com inteligência artificial. Este repositório acompanha o curso e reúne exemplos prontos para adaptar ao seu projeto.

## Como usar

1. Encontre o prompt pelo tema na tabela abaixo.
2. Abra o link e copie o bloco do prompt.
3. Substitua os campos entre colchetes pelo contexto do seu projeto e envie à sua ferramenta de inteligência artificial.

## Prompts disponíveis

| Tema | Prompt | Quando usar |
| --- | --- | --- |
| Desenvolvimento de sistemas | [Planejar e desenvolver uma funcionalidade](prompts/desenvolvimento/planejar-e-desenvolver-funcionalidade.md) | Explorar ideias e implementar uma funcionalidade simples. |

## Organização

Os prompts ficam na pasta `prompts`, separados por tema. Cada arquivo traz um título, uma orientação de uso e um bloco para copiar.

O guia começa com um exemplo. Os próximos prompts poderão abordar desenvolvimento de sistemas, sistemas de design, manutenção e segurança.
