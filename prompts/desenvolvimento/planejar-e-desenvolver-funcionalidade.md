# Planejar e desenvolver uma funcionalidade

Use este prompt para explorar ideias e desenvolver uma funcionalidade simples. Substitua os campos entre colchetes pelo contexto do seu projeto.

```
Quero desenvolver [FUNCIONALIDADE] no projeto [DESCRIÇÃO DO PROJETO].
Faça uma rodada de ideias e sugira três soluções simples para essa necessidade.
Compare as opções e recomende a solução mais adequada ao contexto do projeto.
Implemente a solução recomendada seguindo os padrões existentes do projeto.
Verifique o resultado e explique o que mudou e como testar a funcionalidade.
```
